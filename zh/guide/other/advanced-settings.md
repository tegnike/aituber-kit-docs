# 高级设置

## 备份与恢复设置

您可以将当前浏览器中保存的AITuberKit设置下载为JSON文件，并导入到其他浏览器或设备中。请在设置界面的“高级设置”中进行操作。

### 下载设置

点击“下载设置”后，当前设置将保存为名为 `aituber-kit-settings-YYYYMMDD-HHMMSS.json` 的文件。

默认情况下，下载的文件不包含API密钥等敏感信息。如果需要完整迁移设置，请先启用“包含API密钥等敏感信息”，再下载设置。

:::warning 包含敏感信息时
API密钥、认证请求头、自定义API请求正文、信息亭模式密码等内容将以明文形式保存到JSON文件中。请勿公开或共享该文件，并将其保存在安全的位置。
:::

### 导入设置文件

通过“导入设置文件”选择AITuberKit的设置JSON文件，并在确认对话框中同意后，设置将生效，页面也会重新加载。可导入文件的大小上限为5MB。

- 导入不含敏感信息的文件时，将保留当前浏览器中保存的API密钥等信息
- 导入包含敏感信息的文件时，API密钥等信息也会被文件中的内容覆盖
- 旧版设置会在支持的范围内转换为当前格式后导入
- 不支持的格式、无效值，以及包含高于当前应用所支持设置版本的文件无法导入

### 备份中不包含的内容

此功能仅备份浏览器中的设置值，不包含以下文件本身或数据。

- 角色模型、背景、已放置图像和幻灯片的文件本身
- 对话历史
- 长期记忆的文件和数据
- `.env`、`.env.local` 等环境变量文件

环境变量与设置文件分开管理。当 `NEXT_PUBLIC_ALWAYS_OVERRIDE_WITH_ENV_VARIABLES=true` 时，环境变量会始终覆盖浏览器设置，因此无法导入设置文件。

## 重置设置

您可以重置AITuberKit的设置，并恢复到初始状态。

:::warning 注意
执行重置操作后，除对话历史外的所有设置都将恢复为默认值，并且页面将重新加载。如果设置了环境变量，则这些值将优先应用。
:::

## 调试日志

如果希望客户端生产构建也输出调试用的 `logger.log`，请启用此设置。该值会在构建时嵌入客户端包，因此请在构建前进行设置。无论此设置如何，服务器端日志都会输出。

```bash
# 客户端生产构建的调试日志（true/false）
NEXT_PUBLIC_DEBUG_LOG="false"
```

## 背景视频设置

可以使用共享屏幕或网络摄像头视频作为背景。使用多模态功能时，还可以将背景视频的屏幕截图发送给AI。

**环境变量**:

```bash
# 背景视频使用设置（true/false）
NEXT_PUBLIC_USE_VIDEO_AS_BACKGROUND="false"
```

## 视频显示隐藏设置

即使在屏幕共享或使用网络摄像头期间，也可以隐藏屏幕上显示的视频预览（背景显示或浮动显示）。由于捕获本身仍在继续，因此可以在保持向AI发送图像以及游戏解说模式捕获功能有效的同时，使屏幕布局更加简洁。

即使预览处于隐藏状态，也可以随时点击视频操作按钮中的"+"图标重新显示。

**环境变量**:

```bash
# 视频显示隐藏设置（true/false）
NEXT_PUBLIC_HIDE_VIDEO_DISPLAY="false"
```

## 快捷菜单显示设置

您可以切换主页上显示的快捷菜单按钮的显示状态。您可以根据需要关闭此选项以保持屏幕简洁。

**环境变量**:

```bash
# 快捷菜单显示设置（true/false）
NEXT_PUBLIC_SHOW_QUICK_MENU=true
```

## 时间戳设置

您可以设置是否在用户发言中包含时间戳（UTC）。包含时间戳可以让AI在生成响应时考虑时间因素。

:::tip
要利用此功能，请在系统提示中包含如下文本：

"当用户输入带有[timestamp]时，这表示请求时的UTC时区时间，所以请在生成响应时考虑该时间。"
:::

**环境变量**:

```bash
# 时间戳包含设置（true/false）
NEXT_PUBLIC_INCLUDE_TIMESTAMP_IN_USER_MESSAGE=false
```

## 预设问题

此功能允许您在UI中显示预定义的问题，可以通过单击发送。注册常用问题或标准短语非常方便。

![预设问题](/images/other_c3sa5.webp)

### 基本操作

- 添加问题：在文本输入字段中输入问题，然后点击"+"按钮
- 编辑问题：直接编辑已注册问题的文本
- 删除问题：点击"-"按钮
- 重新排序问题：拖动问题左侧的手柄（⋮⋮）以更改顺序

### 切换显示

您可以切换问题的显示状态。如果您不使用此功能，可以关闭此选项以保持UI简洁。

**环境变量**:

```bash
# 预设问题显示设置（true/false）
NEXT_PUBLIC_SHOW_PRESET_QUESTIONS=true
# 预设问题文本（逗号分隔）
NEXT_PUBLIC_PRESET_QUESTIONS=今天天气怎么样？,请做个自我介绍,你最喜欢的食物是什么？,告诉我最近的新闻
```
